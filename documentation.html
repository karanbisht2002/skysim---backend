esimConnect

The most advanced eSIM marketplace platform. Enterprise-grade customer portal, B2B modules, multi-provider integration, and automated deployments.

Introduction

esimConnect v2 is a state-of-the-art eSIM marketplace and management platform designed for global connectivity. It enables businesses to launch their own eSIM brand with direct integrations into leading providers like Airalo, eSIM Access, eSIM Go, and Maya.

The platform is split into three core modules: a Customer-Facing Portal for retail sales, an Enterprise B2B Dashboard for corporate clients/resellers, and a Powerful Admin Panel for platform operators to manage everything from package margins to multi-language translations.

Installation Guide

Follow these meticulously detailed steps to deploy esimConnect on your production server.

2. Install Dependencies & Tools

  • 2.1 Update System Packages

    First, update all system packages to ensure you have the latest security patches:

    sudo apt update && sudo apt upgrade -y

  • 2.2 Install Node.js 20+

    The platform requires Node.js 20 or higher for full ES Module support.

    curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node --version && npm --version

  • 2.3 Install PostgreSQL Database

    sudo apt install -y postgresql postgresql-contrib
psql --version

  • 2.4 Install PM2, Nginx & Certbot

    sudo npm install -g pm2
sudo apt install -y nginx certbot python3-certbot-nginx

3. Database Setup & Configuration

  • 3.1 Create Database & User

    sudo -u postgres psql

CREATE DATABASE esimconnect;
CREATE USER esimconnect_user WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE esimconnect TO esimconnect_user;
\q
    ⚠️

    Replace 'your_secure_password' with a strong password (minimum 16 characters, mixed case, numbers, special chars).

  • 3.2 Test Database Connection

    psql -h localhost -U esimconnect_user -d esimconnect -c "SELECT version();"
    ✅

    If you see the PostgreSQL version, your database is properly configured.

4. Application Installation

  • 4.1 Extract & Set Permissions

    cd /var/www/
sudo unzip esimconnect.zip
sudo mv esimconnect-main esimconnect
sudo chown -R $USER:$USER esimconnect
cd esimconnect

  • 4.2 Install Dependencies & Set Permissions

    npm install
sudo chown -R $USER:$USER node_modules
chmod -R 755 .
    ✅

    All application dependencies installed successfully.

5. Environment Variables Configuration

  • 5.1 Copy & Edit .env File

    cp .env.example .env
nano .env

  • 5.2 Database Configuration

    DATABASE_URL=postgresql://esimconnect_user:your_secure_password@localhost:5432/esimconnect
PORT=5000
NODE_ENV=production
BASE_URL=https://yourdomain.com

6. SSL Certificate & Web Server Setup

  • 6.1 Generate SSL Certificate

    sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

  • 6.2 Configure Nginx

    Create a new configuration file:

    sudo nano /etc/nginx/sites-available/esimconnect

    Add the following configuration:

    server {
    listen 80;
    server_name yourdomain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yourdomain.com;

    ssl_certificate /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    location / {
        proxy_pass http://localhost:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}

  • 6.3 Enable & Test Nginx

    sudo ln -s /etc/nginx/sites-available/esimconnect /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
    ✅

    Nginx configured with SSL enabled.

7. Database Migrations & Launch

  • 7.1 Run Database Migrations

    cd /var/www/esimconnect

npm run db:push
npm run db:seed
npm run db:seedAdmin
npm run db:seedProvider

  • 7.2 Verify Database Tables

    psql -h localhost -U esimconnect_user -d esimconnect -c "\dt"
    ✅

    Tables created: users, orders, packages, enterprise_accounts, etc.

  • 7.3 Initial Admin Access

    Once the seeds are finished, you can log in to the Admin Panel (/admin) using these default credentials:

    Email: admin@gmail.com
Password: Admin@123
    ⚠️

    Please change your password immediately after the first login for security reasons.

  • 7.4 Start Application with PM2

    pm2 start npm --name "esimconnect" -- start
pm2 startup systemd -u $USER --hp /home/$USER
pm2 save
pm2 list
    🚀

    Application is now running! Visit https://yourdomain.com

  • Manage Translations

    To provide translations for a new language:
    1. Create the corresponding JSON file for that language based on the English template.
    2. Upload/Import it via the Translations tab in the Admin Panel.
    3. Once done, the language and its translations will be successfully available system-wide.

  • Default Locale Files

    The standard translation files for the frontend are located at:

    client/src/locales/
    💡

    You can use these as templates for creating new language JSON files.

Help & Support

⚠️
Missing QR Codes?

Ensure your BASE_URL is correctly set to your production domain. QR codes are generated dynamically and saved to the uploads/ directory.

Troubleshooting Common Issues

  • Database Connection Error

    Ensure your DATABASE_URL is correctly formatted. If using Neon, ensure sslmode=require is appended to the string.

  • Stripe Webhook Not Updating Status

    Ensure you have configured the Stripe Webhook URL in your Stripe Dashboard. It should point to https://yourdomain.com/api/webhooks/stripe.

  • Provider Sync Failures

    If package syncing times out, check your server's outbound firewall rules and verify that your API keys for Airalo/eSIM Go are active and valid.

  • Email (SMTP) Issues

    Verify that your SMTP_PASS is an App Password if using Gmail. Standard passwords will be rejected by Google's security layers.

  • Permissions Issues

    If images aren't uploading, run: sudo chown -R www-data:www-data storage/ uploads/ on your server.

Important (IMP) Production Tips

💡
PWA Support

To enable the "Install App" prompt, ensure your BASE_URL is HTTPS and all manifest icons in public/ are correctly linked.

🛡️
JWT & Session Security

Never share your JWT_SECRET or SESSION_SECRET. If compromised, regenerate them immediately to force-logout all active users.

⚙️
Admin Activity Tracking

The system logs all major admin actions (deletions, price changes). You can monitor these movements in the Notification History tab.

Updating the Platform

Follow these steps whenever you receive a new version of the code or want to pull the latest changes.

  • 1. Upload New Code

    Upload the new esimconnect.zip and extract it, overwriting the existing files (keeping your .env file safe).

  • 2. Update Dependencies

    npm install

  • 3. Apply Database Changes

    Run the migration tool to update your database schema to the latest version:

    npm run db:push

  • 4. Rebuild & Restart

    Re-compile the application and restart the process manager:

    npm run build
pm2 restart esimconnect
✨
Update Complete! Your system is now running the latest version.
